Liens de redirection depuis JOSM

Dans le logiciel JOSM, le plug-in UtilsPlugin2 permet d'ouvrir une page web grâce aux coordonnées du centre de la zone qu'on édite.

Certains sites thématiques comme Pifomètre, Clochers.org ou MemorialGenWeb, utilisent les communes françaises comme point d'entrée.

Bano.openstreetmap.fr héberge un outil qui fait le lien entre les deux : il identifie, d'après les coordonnées JOSM, la commune française où l'on se trouve et permet donc d'ouvrir directement la page correspondante sur le site cible.

Les liens :

  • Pifomètre : https://bano.openstreetmap.fr/outils/josm.html?lat={#lat}&lon={#lon}

    • Pour ouvrir la page de la commune sur Pifomètre.

  • Pifomap : https://bano.openstreetmap.fr/outils/josm_pifomap.html?lat={#lat}&lon={#lon}

    • Pour ouvrir la page de la commune sur Pifomap.

  • Topo : https://bano.openstreetmap.fr/outils/josm_topo.html?lat={#lat}&lon={#lon}

    • Pour ouvrir la page de la commune sur la page "fichier Topo".

  • MemorialGenWeb : https://bano.openstreetmap.fr/outils/memorialgenweb.html?lat={#lat}&lon={#lon}

    • Pour ouvrir la page de la commune sur MemorialGenWeb et voir la liste de ses monuments aux morts, dont le numéro de relevé est la valeur attendue pour le tag ref:FR:MemorialGenWeb.

  • Clochers.org : https://bano.openstreetmap.fr/outils/clochers.html?lat={#lat}&lon={#lon}

    • Pour ouvrir la page de la commune sur Clochers.org et voir la liste de ses clochers, dont le numéro de relevé est la valeur attendue pour le tag ref:clochers.org.

Pour paramétrer un raccourci :

  • Si ce n'est pas déjà fait : dans JOSM, installer le plug-in UtilsPlugin2 (touche F12 > colonne de gauche > Greffons)
  • Aller dans les paramètres de ce plug-in (touche F12 > colonne de gauche > Paramètres de UtilsPlugin2)
  • insérez une ligne dans la colonne de droite et un nom dans la colonne de gauche

Pour utiliser le raccourci :

Dans JOSM, si le centre de votre affichage est sur une commune française, tapez Maj + H et choisissez le site souhaité (Pifomètre, MemorialGenWeb...) dans la liste. Une page web va s’ouvrir dans votre navigateur par défaut.

Si vous décochez par erreur la case "Demander à chaque fois" et que la pop-up de choix n'apparaît plus quand vous faites Maj + H, allez dans les paramètres avancés de JOSM (F12 > Paramètres avancés), cherchez le paramètre utilsplugin2.askurl et passez la valeur de false à true.

Calques dans JOSM

Limites communales :

Ce calque permet de visualiser dans JOSM les limites de communes fournies par le Cadastre et préparées par data.gouv.fr. On peut l'afficher par-dessus un calque d'imagerie, par exemple. Comme chaque commune définit ses propres limites, la frontière entre deux communes apparaît souvent dédoublée, et c'est normal. Aucune n'est plus "juste" que l'autre a priori.

Les URL :

  • Limites en jaune : https://bano.openstreetmap.fr/outils/cadastre_communes_jaune.json
  • Limites en mauve : https://bano.openstreetmap.fr/outils/cadastre_communes_mauve.json
  • Limites en vert : https://bano.openstreetmap.fr/outils/cadastre_communes_vert.json

Comment configurer le calque :

  • Dans JOSM, ouvrir le menu Imagerie > Préférences d'imagerie
  • En bas à droite de la fenêtre, cliquer sur le bouton «+ MVT». Une pop-up s'ouvre.
  • Dans la première zone, collez l'URL selon la couleur souhaitée.
  • Dans la deuxième zone (niveau de zoom), indiquez "24".
  • Dans la quatrième et dernière zone, indiquez le nom souhaité pour votre calque (par ex : "Limites jaune")

Une fois cette configuration validée, le calque apparaît dans la liste des calques disponibles dans le menu Imagerie.
